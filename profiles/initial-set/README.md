# initial-set

通常の開発プロジェクト向けの初期セットです。

## コピー対象

| コピー元 | コピー先 | 必須 |
|---|---|---|
| `.skills/` | 対象プロジェクトの `.skills/` | はい |

## 含まれる領域

- 要件探索
- 既存調査
- バグ調査
- データフロー整理
- SaaS / 機能仕様整理
- DB 設計
- API 設計
- プロンプト設計
- 実装仕様書作成
- 実装計画
- コードレビュー
- セキュリティレビュー
- migration レビュー
- UI/UX レビュー
- リファクタ計画
- テスト計画

## 使わないケース

HP 作成だけで最小限にしたい場合でも、この初期セットをベースにします。不要な skill は呼び出さなければよく、コピー時に個別削除しても構いません。
