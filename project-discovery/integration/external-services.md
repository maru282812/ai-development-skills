# 外部サービス連携: CLEAN TOILET(仮)

更新日: 2026-06-20

## 目的

外部サービスの料金、無料枠、API制限、商用利用条件、契約者、請求先、アップロード先を、実装後に散らばらせず管理できるようにする。

この文書では実装方式やDB設計は確定しない。後工程で管理画面・データ設計・契約確認に渡すための外部依存を整理する。

## 管理画面で持つ外部サービス台帳

| 項目 | 内容 |
|---|---|
| サービス名 | Google Maps Platform、Supabase等 |
| 用途 | 地図表示、画像保存、AIぼかし、決済、通知等 |
| 契約者/管理者 | 誰のアカウントで契約しているか |
| 請求先 | 法人/個人、カード、請求書払い等 |
| 契約プラン | Free、Pro、従量課金、年額等 |
| 公式料金URL | 料金確認先 |
| 商用利用条件URL | 利用規約、商用利用条件、ブランド/表示条件等 |
| 無料枠 | 無料利用枠、クレジット、無料上限 |
| API制限/クォータ | 1日、1分、月間、同時実行等 |
| 従量課金単位 | リクエスト、GB、MAU、ビルド分、決済額等 |
| 確認日 | 公式情報を最後に確認した日 |
| 月額見込み | MVP/β/正式公開ごとの想定 |
| 実請求額 | 月次で入力 |
| アラート閾値 | 80%、100%、金額上限など |
| 備考 | 価格改定、制限、契約上の注意 |

## 主要サービス候補

| サービス | 用途 | コストドライバー | 状態 | 管理上の注意 |
|---|---|---|---|---|
| Google Maps Platform | 地図表示、Places、Geocoding、Routes候補 | 地図表示、検索、経路、リクエスト数 | MVP採用方針 | 料金・無料枠・API制限・商用利用条件を公式URLで確認する |
| Supabase | DB、Auth、Storage、Edge Functions、PostGIS候補 | プラン、DB容量、ストレージ、転送量、関数実行 | MVP採用方針 | 組織単位の請求、固定費 + 従量課金を管理する |
| Supabase Storage | 写真ステップ、ぼかし後画像、通報証跡候補 | 保存容量、転送量、画像変換 | MVP採用方針 | 公開画像と非公開証跡を分ける |
| Expo/EAS | ビルド、配布、OTA更新 | ビルド分、更新配信、MAU、並列数 | MVP採用方針 | TestFlight/Google Play配布と合わせて確認する |
| Apple Developer Program | iOS配布、TestFlight | 年額登録費、契約更新 | 必須候補 | 契約者と更新日を管理する |
| Google Play Console | Android配布、クローズドテスト | 初回登録費、テスト/公開要件 | 必須候補 | 個人/組織アカウントの確認が必要 |
| Stripe | B2B掲載料、スポンサー枠、請求 | 決済額、手数料、返金 | Phase2採用候補 | 掲載プランと返金条件確定後に設計する |
| RevenueCat | 一般ユーザー向けアプリ内課金候補 | MAU、売上、プラン | 将来候補 | 広告非表示、スキン、称号装飾等を入れる場合に検討する |
| AI画像処理 | 顔検出、ぼかし、不適切画像判定、通報分類 | 画像枚数、解像度、推論回数 | 要確認 | MVPではコスト上限を決め、必要最小限にする |
| 通知/メール | 注意通知、問い合わせ、スポンサー連絡 | 送信数、MAU | 要確認 | 法務・同意・配信停止も確認する |
| メール送受信/問い合わせ管理 | 問い合わせ受付、受信確認、返信履歴、管理者通知 | 送受信数、保存期間 | 要確認 | MVPではメールと管理画面で対応する |
| AI問い合わせ補助 | 問い合わせ分類、優先度付け、類似回答検索、返信下書き | 問い合わせ件数、トークン/リクエスト数 | 要確認 | 外部送信前に人間が確認する |
| LP/管理画面ホスティング | LP、スポンサー申込、管理画面 | 月額、転送量、ビルド | 要確認 | Web/PWAは本体ではなく周辺用途に限定 |
| 監視/ログ | 障害検知、操作ログ、費用監視 | イベント数、保存期間 | 要確認 | 管理操作と費用アラートを残す |

## 駅/施設/海外データソース

駅構内図、駅設備、商業施設トイレ情報、号車情報は公式情報を正にする。
外部データは初期候補、重複照合、海外調査の補助として扱い、公式情報や運営確認を上書きしない。

| データソース | 主な用途 | MVPでの位置づけ | 注意点 |
|---|---|---|---|
| 鉄道事業者/駅公式情報 | 駅構内図、駅設備、改札内外、トイレ位置、号車案内 | 正本 | 画像/PDF/構内図の転載、保存、加工、商用利用は許諾確認が必要 |
| 商業施設公式情報 | フロア別トイレ、利用条件、営業時間、施設内導線 | 正本 | 施設マップ画像は権利確認なしに保存しない |
| 施設/店舗/テナントオーナー提供 | 公式写真、公式ルートカード、スポンサーコード、利用条件 | 公式扱い候補 | 申請者確認と運営承認を通す |
| GTFS / GTFS Pathways | 駅、ホーム、出入口、構内ノード、階層、乗車位置候補 | 海外/交通データの補助 | 提供有無と粒度は事業者ごとに異なる。トイレ詳細は保証されない |
| Google Places | `public_bathroom` などの候補地点、施設候補の探索 | 候補データ | 駅構内の階層、個室数、改札内外、導線は保証されない。地域や契約条件も確認が必要 |
| OpenStreetMap | `amenity=toilets`、`toilets:*`、施設内トイレ候補 | 候補データ/照合 | 地域差、タグ揺れ、ライセンス表記が必要。正本にはしない |
| ユーザー投稿 | 清潔度、安心度、迷いやすさ、写真ステップ、満室/閉鎖など | 現地補足 | 公式を直接上書きしない。確認状態と信頼度を分ける |

海外展開では、国/都市/データ種別ごとに信頼度を持つ。
公式または複数ソースで確認できる地域から段階展開し、未検証データは「未確認」と明示する。

## アップロード先管理

| データ種別 | 初期候補 | 公開範囲 | 保存方針 | 注意 |
|---|---|---|---|---|
| 写真ステップ画像 | Supabase Storage候補 | 公開 | 圧縮後画像を保存 | 原寸保存は原則しない |
| トイレ内写真 | Supabase Storage候補 | 確認後公開 | 投稿前確認、公開前スキャン必須 | 人物・鏡・個人情報・個室内疑いは非公開 |
| 自動ぼかし後画像 | Supabase Storage候補 | 公開 | 公開用として保存 | 元画像と分ける |
| 元画像 | Supabase Storage候補 | 非公開 | 必要最小限の保持 | 削除依頼・通報対応後の保持期間を要確認 |
| 通報証跡 | Supabase Storage/DB候補 | 非公開 | 運営確認用 | 個人情報・証跡保持期間を要確認 |
| CSV/レポート | 管理画面/Storage候補 | 非公開 | 管理者用 | 支援者・スポンサー情報を含む場合は注意 |
| ログ | 監視/ログ基盤候補 | 非公開 | 期間を決めて保持 | 個人情報を最小化 |

## 公式確認メモ

- Google Maps Platform はプロダクトや地域によって料金・条件が変わるため、正式採用前に公式Pricingと利用規約を確認する。
- Supabase はプランと従量課金があるため、DB、Storage、Edge Functions、転送量を別々に見積もる。
- Expo/EAS はビルド、OTA更新、利用量がコスト要因になるため、TestFlight/Google Playの配布計画と合わせて確認する。
- Apple Developer Program と Google Play Console はアプリ公開・テスト配布の前提になる。

## 2026-06-20時点の公式確認メモ

| 対象 | 公式確認できた要点 | 管理画面で確認する項目 |
|---|---|---|
| Google Maps Platform | 料金は利用プロダクト/SKU/地域/契約条件で変わる。EEA向けは条件が異なる場合がある | Maps SDK、Places、Geocoding、Routes等の有効API、無料枠、クォータ、月額見込み、実績 |
| Supabase | Free/Pro/Team/Enterprise等のプランと従量課金がある | DB容量、Storage容量、転送量、Edge Functions、Auth、契約プラン |
| Supabase Storage | 画像/動画等のファイル保存と配信に使える | バケット、公開/非公開、保存容量、転送量、画像変換、削除条件 |
| Expo/EAS | ビルド、CI/CD、OTA更新、MAU/利用量がコスト要因になる | ビルド分、更新配信、MAU、チーム/プラン、月額見込み |
| Apple Developer Program | アプリ配布やTestFlight利用には開発者プログラム加入が必要 | 契約者、年額費用、更新日 |
| Google Play Console | Androidアプリ配布には開発者アカウント登録が必要 | 契約者、登録費、公開/テスト条件 |

注: 金額は改定されるため、この文書では固定せず、管理画面上の外部サービス台帳に公式URL・確認日つきで登録する。
