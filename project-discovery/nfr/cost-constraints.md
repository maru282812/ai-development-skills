# コスト制約: CLEAN TOILET(仮)

更新日: 2026-06-20

## 目的

CLEAN TOILET(仮) は、地図、位置情報、画像投稿、AI画像処理を扱うため、利用が増えるほど維持費が増える。MVPでは機能を増やすだけでなく、月額費用・API制限・保存容量を管理できる状態にする。

## 基本方針

- 料金、無料枠、API制限、商用利用条件は公式URLと確認日つきで管理する。
- 料金表の数値を要件定義書に固定しない。
- MVPでは自動課金連携より、管理画面の台帳、手入力、CSV出力を優先する。
- 地図API、画像ストレージ、AI画像処理は主要な変動費として別枠で監視する。
- 画像は原寸保存を避け、公開用の圧縮画像を基本にする。
- 動画投稿はMVPでは扱わない。

## 管理すべきコスト項目

| コスト項目 | MVPの最低ライン | 将来の理想 | 状態 |
|---|---|---|---|
| 地図API | リクエスト数、月額見込み、実績、アラート閾値を管理 | API別/SKU別に自動集計 | 決定 |
| Places/Geocoding/Routes | 利用APIと用途を明確化し、不要なAPIを有効化しない | 駅検索・ルート案内の利用状況に応じて最適化 | 決定 |
| DB | Supabaseプラン、容量、接続数を管理 | 成長に応じてプラン最適化 | 決定 |
| 画像ストレージ | 圧縮後画像を保存し、容量と転送量を月次確認 | 画像変換/CDN最適化 | 決定 |
| AI画像処理 | 顔検出/ぼかし/不適切画像判定の件数を管理 | 精度とコストのバランスでサービス選定 | 決定 |
| 通知/メール | 注意通知・問い合わせ用途に限定 | 配信停止・テンプレート管理 | 要確認 |
| ビルド/配布 | Expo/EAS、TestFlight、Google Playの費用を管理 | CI/CD利用量の自動確認 | 決定 |
| 決済/請求 | MVPは手動請求、Phase2以降にStripeを採用候補にする | プラン課金、請求書、返金管理 | 決定 |
| アプリ内課金 | MVPでは扱わない | RevenueCat等で広告非表示/スキン等を検討 | 将来候補 |
| 管理画面ホスティング | LP/管理画面/スポンサー申込の月額費用を管理 | 監視とログを統合 | 要確認 |
| 監視/ログ | 重要ログと費用アラートを残す | ダッシュボード化 | 要確認 |

## 月額上限とアラート

MVP一般公開時の外部サービス月額上限は、いったん 50,000円/月 とする。
先行ベータでは 30,000円/月 を目安に抑える。
100,000円/月 への引き上げは、スポンサー収益、クラウドファンディング残額、または運営資金の見込みが立ってから判断する。

| コスト項目 | MVP月額上限 | 注意アラート(70%) | 警告アラート(85%) | 超過時の初期対応 |
|---|---:|---:|---:|---|
| 地図API | 15,000円 | 10,500円 | 12,750円 | 地図表示範囲、Places/Geocoding/Routes呼び出し、検索リトライを見直す |
| DB/Auth/Functions | 8,000円 | 5,600円 | 6,800円 | 重い検索、ログ、Edge Functions実行回数を確認する |
| 画像ストレージ/転送量 | 5,000円 | 3,500円 | 4,250円 | 画像圧縮率、1投稿あたり枚数、古い画像のアーカイブを見直す |
| 画像変換/ぼかし/AI審査 | 7,000円 | 4,900円 | 5,950円 | 再監査頻度、審査対象、画像解像度を見直す |
| 通知/メール | 2,000円 | 1,400円 | 1,700円 | 注意通知・問い合わせ通知の頻度とテンプレートを見直す |
| ビルド/配布/OTA | 4,000円 | 2,800円 | 3,400円 | EASビルド回数、OTA配布頻度を見直す |
| LP/管理画面/監視/ドメイン | 5,000円 | 3,500円 | 4,250円 | ログ保持期間、監視項目、ホスティングプランを見直す |
| 決済手数料 | 1,000円 + 売上連動 | 700円 | 850円 | 手数料率、請求方法、プラン価格を確認する |
| 予備費 | 3,000円 | - | - | 突発的な追加費用に使う |
| 合計 | 50,000円 | 35,000円 | 42,500円 | 100%到達で運営判断、120%到達で高コスト機能を一時制限 |

アラート運用:
- 70%到達で注意アラートを出す
- 85%到達で警告アラートを出し、原因カテゴリを確認する
- 100%到達で運営者確認なしに追加施策を打たない
- 120%到達で画像再監査頻度、地図API呼び出し、画像アップロード上限などの高コスト機能を一時制限する
- 上限超過時も、緊急時の `今すぐトイレ` 体験は止めない

## アップロード制約

| データ種別 | MVP制約 | 理由 |
|---|---|---|
| 写真ステップ画像 | 1ルートあたり最大3枚程度から開始 | 投稿体験と容量のバランス |
| トイレ内写真 | 任意。投稿前確認と公開前スキャン必須 | プライバシーリスクが高い |
| 元画像 | 原則保存しない。必要な場合は短期・非公開 | 容量と個人情報リスクを下げる |
| ぼかし後画像 | 公開用として保存 | 顔映り込み対応 |
| 動画 | MVP対象外 | 容量・人物映り込み・審査負荷が大きい |
| 通報証跡 | 非公開、保持期間を定める | 運営判断と法務確認用 |

## 実装/運用時に公式確認して台帳登録する項目

- Google Maps Platform の料金、無料枠、API制限、商用利用条件
- Supabase のプラン、Storage、転送量、Edge Functions、Authの制限
- AI画像処理のサービス選定と1画像あたりの概算
- Apple / Google の開発者登録、公開、テスト配布の条件
- Stripe / RevenueCat を使う場合の手数料、返金、アプリ内課金ルール
