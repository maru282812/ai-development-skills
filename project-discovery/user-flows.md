# 利用者導線

更新日: 2026-06-21

## 初回利用/ユーザー承認（アプリ起動 → 同意 → 利用開始）

1. アプリを起動する
2. 初回表示で、利用条件とプライバシーポリシーへの導線を表示する
3. 匿名閲覧は開始できる
4. アカウント作成時に、利用規約とプライバシーポリシーの明示同意を取る
5. 同意ログを保存する

分岐:
- 位置情報を使う場合: OS権限の前に利用目的を説明し、拒否時は駅名検索へ誘導する
- 規約更新がある場合: 重要変更時は再同意を求める
- 未同意の場合: 閲覧以外の投稿、評価、写真、地点提案、SNS共有、支援者連携は利用できない

## 今すぐトイレ（アプリ起動 → 最短候補 → 案内開始）

1. アプリを起動する
2. `今すぐトイレ` を選択する
3. 位置情報の利用目的を確認し、OS権限で許可する
4. アプリが候補を自動表示する
   - 最短候補
   - 安心候補
   - 空いていそうな候補
   - 代替候補
5. ユーザーは候補を1つ選ぶ
6. ルートカードまたは地図案内を表示する
7. トイレに到着する

分岐:
- 位置情報を拒否した場合: 駅名検索または施設名検索へ誘導
- 周辺に0件の場合: 近隣駅・隣接商業施設の候補を表示
- 緊急時モードでは広告を非表示または最小表示にする
- スポンサー目印は道案内に役立つ場合のみ表示する

## 駅攻略（駅検索 → 号車/改札/階数 → トイレ候補）

1. 駅名を入力する
2. 駅攻略ページを開く
3. 改札内/改札外、路線、方面、階数を確認する
4. 近いトイレ候補を比較する
5. 号車ヒントまたは改札からの写真ステップを見る
6. 必要に応じて隣接商業施設の代替候補を見る

分岐:
- 号車情報が未登録の場合: 「号車情報を投稿する」導線を表示
- 商業施設候補が閉店時間外の場合: 表示優先度を下げる
- 駅全体が複雑な場合: 改札・路線単位に分割して表示

## 写真ステップ投稿（トイレ詳細 → ルートカード投稿）

1. トイレ詳細を開く
2. 「行き方を投稿」を選択する
3. 未ログインの場合はログイン/登録へ進む
4. 初回写真投稿時は投稿/撮影ガイドラインに同意する
5. スタート地点を選ぶ
   - 号車付近
   - 改札
   - 出口
   - 施設入口
   - フロア上の目印
6. 写真を1〜3枚追加する
7. 各写真にチップを付ける
   - 右へ / 左へ / 直進
   - 階段 / エスカレーター / エレベーター
   - B1F / 1F / 2F など
   - 目印あり / 入口わかりにくい
8. トイレ種別を選ぶ
   - 男性
   - 女性
   - 共用
   - 多目的
   - ベビー設備
   - オストメイト
9. 任意で個室数・混雑傾向を追加する
10. トイレ内写真が含まれる場合、投稿前に毎回ポップを表示する
   - 人物が写っていない
   - 鏡越しに人・顔・個人情報が写っていない
   - 私物や個人が特定できるものが写っていない
   - 撮影禁止表示がない
   - 利用中の個室や個室内の様子が写っていない
11. 投稿する
12. アプリが公開前自動スキャンを行う
13. 問題がなければ公開し、投稿完了画面で称号・貢献表示・SNSカード候補を表示する

分岐:
- 顔だけ検出された場合: 自動ぼかし後に公開する
- 人物全身、鏡、個人情報、トイレ個室内、不適切画像の疑いがある場合: 確認待ちにする
- トイレ内写真で人物・鏡・個人情報・個室内の疑いがある場合: 公開せず、確認待ちまたは非公開にする
- 駅や施設までの道のりで避けにくく人物が写った場合: ぼかしや保留の対象にはするが、注意・違反カウントの対象にはしない
- 写真に人物が写っている可能性がある場合: 注意表示・ぼかし・再撮影を促す
- 写真アップロード失敗: 再試行または該当Stepを削除
- 必須項目未入力: 該当項目を表示
- 確認待ちになった場合: 「確認後に公開」と表示し、投稿者へ状態を通知する

## 軽量状態投稿（トイレ利用後 → 10秒更新）

1. トイレ詳細または到着後画面を開く
2. 「状態を更新」を選択する
3. チップを選ぶ
   - 空いてた / 混んでた / 満室気味
   - 清潔 / 普通 / 厳しい
   - 使えた / 入れなかった / 入ったけどやめた
   - 故障 / 閉鎖 / 利用制限あり
   - 怖い / 暗い / 汚すぎた
   - 個室数を更新
   - 入口が分かりにくい
   - 工事中 / 閉鎖
4. 投稿する

分岐:
- 未ログインでも投稿できる
- ゲスト投稿は一時状態として扱い、信頼スコア・称号・SNSカードには反映しない
- ログイン済みの場合は投稿履歴に残し、将来の信頼度計算や称号候補に使える

## 新規トイレ地点提案（未登録地点発見 → 提案完了）

1. 地図ホーム、駅攻略、またはトイレ詳細の「未登録のトイレを提案」を選択する
2. 未ログインの場合はログイン/登録へ進む
3. 施設/建物を選ぶ、または新規施設として入力する
4. 階数、改札内/外、トイレ種別を入力する
   - 男性
   - 女性
   - 共用
   - 多目的
   - ベビー設備
   - オストメイト
5. 任意で個室数、入口写真、目印を追加する
6. 重複候補が出た場合は既存地点への情報追加に切り替える
7. 同じ建物内に複数トイレがある場合は「同じ建物に続けて追加」を選ぶ
8. 提案する

分岐:
- 短時間に別エリアへ多数登録した場合: 上限表示または管理者確認待ちにする
- 同一建物内で複数階・種別違いを連続登録する場合: 建物単位の登録セッションとして扱う
- 情報が不足している場合: 下書きまたは確認待ちにする
- 悪質または重複の可能性が高い場合: 公開せず管理者確認に回す

## スポンサーコード利用（ルート確認 → コード提示）

1. ルートカードまたはトイレ詳細でスポンサー目印を見る
2. スポンサーコードを表示する
3. PR/Sponsored 表記と特典条件を確認する
4. 対象店舗でコードを提示する
5. 必要に応じて「使った」ボタンを押す

分岐:
- 緊急時モードではスポンサーコードを折りたたむ
- 期限切れコードは表示しない
- スポンサーと安心度評価は混ぜない

計測:
- コード表示数を主指標にする
- タップ数を補助指標にする
- 「使った」ボタンは自己申告利用数として扱う
- 店舗報告は任意の補助指標にする

## 施設情報修正/オーナー申請（施設詳細 → 申請完了）

1. 施設詳細、トイレ詳細、またはLPから「施設情報を修正/掲載したい」を選択する
2. 申請種別を選ぶ
   - 公式情報の修正
   - 施設オーナー申請
   - スポンサー/掲載相談
3. 対象施設、対象トイレ、修正内容、連絡先を入力する
4. 必要に応じて公式サイト、店舗情報、管理者であることを示す資料を添付する
5. 申請を送信する
6. 運営が確認し、手動で反映または差し戻す

分岐:
- MVPでは施設オーナーが直接編集しない
- 公式情報として反映する場合は、ユーザー投稿情報と区別して表示する
- 掲載/広告相談の場合は、プラン種別と掲載期間を確認する
- Phase2以降は施設オーナー簡易編集画面へ移行する

## 通報（詳細/レビュー/ルート → 通報完了）

1. レビュー、ルートカード、地点詳細の通報を選択する
2. 通報理由を選ぶ
3. 補足コメントを入力する
4. 送信する
5. AIが通報理由を分類し、高リスクの場合は一時非公開にする
6. 管理者確認待ちにする

## 支援者導線（先行利用）

1. 支援者へ先行利用案内メールを送る
2. メールリンクまたは支援者コードからアプリを開く
3. アカウントを作成またはログインする
4. 利用規約、プライバシーポリシー、支援者連携への同意を確認する
5. 支援者コードを照合し、アカウントへ先行利用権を紐づける
6. 初期サポーターバッジの表示/非表示を選ぶ
7. 名前掲載を希望する場合は、任意の表示名、掲載範囲、削除依頼方法を確認する
8. 店舗/施設掲載または公式スポンサー掲載リターンの場合は、掲載内容の入力フォームへ進む
9. 公開前プレビューを確認し、明示同意がある場合のみ掲載する
10. 投稿・フィードバックを依頼する

分岐:
- 支援者コードが無効/使用済みの場合: 問い合わせフォームへ誘導する
- 名前掲載を希望しない場合: バッジや先行利用権だけ付与し、公開掲載は行わない
- 削除依頼がある場合: マイページまたは問い合わせフォームから掲載停止を依頼できる。画面には「受付済み」「対応中」「対応完了」の状態だけを表示し、具体的な期限は表示しない
