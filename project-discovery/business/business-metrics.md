# 事業KPI: CLEAN TOILET(仮)

更新日: 2026-06-20

## 利用KPI

| KPI | MVP成功判定への寄与 |
|---|---|
| `今すぐトイレ` 利用数 | 最短体験が使われているか |
| 案内開始率 | 候補表示後に行動へ移っているか |
| 駅検索数 | 駅攻略の需要があるか |
| ルートカード閲覧数 | 写真ステップが価値になっているか |

## 投稿KPI

| KPI | MVP成功判定への寄与 |
|---|---|
| 写真ステップ投稿数 | 投稿動機があるか |
| 軽量状態投稿数 | 文字入力なし投稿が機能しているか |
| 最終確認日更新数 | 情報鮮度が保てるか |
| 投稿完了率 | 投稿フォーマットが重すぎないか |

## 収益KPI

| KPI | MVP成功判定への寄与 |
|---|---|
| スポンサー問い合わせ数 | 企業からの関心があるか |
| スポンサー枠表示数 | 広告在庫が作れるか |
| スポンサーコード表示数 | 広告効果の最低限の計測 |
| スポンサーコードタップ数 | ユーザーの関心度を補助的に見られるか |
| スポンサーコード自己申告利用数 | 成果推定を軽く取れるか |
| スポンサーコード店舗報告数 | 店舗側が任意で成果を補足できるか |

## 継続KPI

| KPI | MVP成功判定への寄与 |
|---|---|
| 再訪率 | 外出時に繰り返し使うか |
| 投稿者継続率 | 称号/貢献が投稿継続につながるか |
| 役に立った数 | 投稿者に価値が返るか |

## 運用KPI

| KPI | MVP成功判定への寄与 |
|---|---|
| 通報件数 | リスク量の把握 |
| 通報対応時間 | 運用できるか |
| 非公開化件数 | 審査負荷の把握 |
| 画像容量/月 | ストレージ費が収益仮説に合うか |
| 地図APIリクエスト数/月 | 地図費用が想定内か |
| AI画像処理件数/月 | ぼかし・審査費用が想定内か |
| 外部サービス月額見込み/実績 | 維持費が収益仮説に合うか |
| コストアラート件数 | 無料枠・API制限・予算超過に近づいていないか |

## MVP成功判定

- 成功とみなす条件:
  - `今すぐトイレ` が利用される
  - 写真ステップ投稿が発生する
  - 駅/施設単位で情報密度が上がる
  - 役に立った反応が発生する
  - スポンサー問い合わせまたは掲載検証が発生する
- 失敗とみなす条件:
  - 投稿が増えず、情報が古いままになる
  - ルート投稿が面倒で完了率が低い
  - 広告表示が邪魔でユーザー体験を損なう
  - スポンサー側が効果を感じない
- 「登録数だけ増えた」を成功にしない理由:
  - トイレ地点数だけでは、今すぐ行けるか、安心できるか、迷わず辿り着けるかが分からないため。
