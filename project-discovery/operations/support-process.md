# サポート・異常時対応: CLEAN TOILET(仮)

更新日: 2026-06-20

## 基本方針

MVPでは、問い合わせ対応をメールと管理画面に集約する。
AIは判断補助として使い、外部への回答や削除・BAN・掲載条件の最終判断は人間が行う。

## 問い合わせ対応

| 経路 | 対応担当 | 一次応答目標 | 解決目標 | AI補助 |
|---|---|---:|---:|---|
| アプリ内問い合わせフォーム | 運営 | 3営業日以内 | 7営業日以内 | 分類、優先度、類似回答、返信下書き |
| 管理画面からの問い合わせ管理 | 運営 | 3営業日以内 | 7営業日以内 | 対応漏れ検知、ステータス提案 |
| メール | 運営 | 3営業日以内 | 7営業日以内 | 本文分類、返信下書き |
| 通報 | 運営 | 高リスクは24時間以内確認 | 3営業日以内 | リスク分類、対象投稿抽出 |
| スポンサー問い合わせ | 運営 | 3営業日以内 | 10営業日以内 | プラン候補、テンプレート下書き |

## 問い合わせカテゴリ

| 種別 | 担当 | 初期対応 | 人間確認が必須の理由 |
|---|---|---|---|
| 通報 | 運営 | AIがリスク分類し、高リスクは確認待ちに寄せる | 誤非公開や投稿者対応の影響が大きい |
| 掲載削除依頼 | 運営 | 対象投稿・施設・理由を確認する | 権利、本人性、公益性の判断が必要 |
| 写真削除依頼 | 運営 | 対象写真と写り込み内容を確認する | 個人情報・肖像・施設権利の判断が必要 |
| 施設情報修正 | 運営 | 公式URLや証明資料を確認する | 公式情報の上書きに関わる |
| オーナー申請 | 運営 | 申請者情報、対象施設、証明資料を確認する | なりすまし防止が必要 |
| スポンサー相談 | 運営 | 掲載希望、対象エリア、期間を確認する | 価格表、契約、広告表記の判断が必要 |
| 外部サービス費用確認 | 運営/開発 | 台帳、請求、アラートを確認する | サービス停止や費用超過に関わる |

## AIに任せる範囲

| 範囲 | 可否 | 備考 |
|---|---|---|
| 問い合わせ分類 | 可 | カテゴリ、緊急度、担当候補を付ける |
| 類似問い合わせ検索 | 可 | 承認済みナレッジから検索する |
| 返信下書き | 可 | 送信前に人間が確認する |
| FAQ系の受信確認 | 可 | 自動返信する場合も固定テンプレートに限定する |
| 投稿削除判断 | 不可 | 人間が最終判断する |
| BAN/投稿制限判断 | 不可 | 人間が最終判断する |
| 法務・返金・契約回答 | 不可 | 専門家確認が必要な可能性がある |
| スポンサー条件の確定 | 不可 | 価格表、契約、掲載条件の確認が必要 |

## 回答ナレッジ蓄積

問い合わせ対応後、個人情報や個別条件を除いた形で回答をナレッジ化する。

| 項目 | 内容 |
|---|---|
| カテゴリ | 通報、削除依頼、施設修正、スポンサー、費用確認など |
| 質問要約 | 個人情報を除いた問い合わせ要約 |
| 最終回答 | 実際に送った回答を元にした標準回答 |
| 根拠 | 規約、投稿ガイドライン、運営方針、公式情報URLなど |
| 承認者 | 回答を再利用可能にした人 |
| 再利用可否 | AI回答候補として使えるか |
| 最終確認日 | 古い回答を使い続けないための確認日 |

## 異常時対応

| 事象 | 検知方法 | 一次対応 | エスカレーション先 | 緊急停止権限者 |
|---|---|---|---|---|
| 不適切画像の大量投稿 | AI審査、通報、投稿急増 | 対象投稿を確認待ちに寄せる | 運営 | 未確定 |
| 個人情報・人物映り込み通報 | 通報、AI分類 | 該当画像を一時非公開 | 運営/法務確認 | 未確定 |
| 施設からの削除依頼 | メール/フォーム | 対象情報を確認し、必要に応じて一時非公開 | 運営/法務確認 | 未確定 |
| 地図API/外部サービス費用超過 | 管理画面アラート | 高コスト機能の一時制限 | 運営/開発 | 未確定 |
| サービス障害 | 監視/ユーザー問い合わせ | 障害告知、復旧確認 | 開発 | 未確定 |
