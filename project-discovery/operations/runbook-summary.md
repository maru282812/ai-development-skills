# 運営開始手順（要約）: CLEAN TOILET(仮)

更新日: 2026-06-20

## 運営開始時に必要な手順

| 順序 | 手順 | 担当 | 前提 |
|---:|---|---|---|
| 1 | 管理者アカウントを作る | 運営/開発 | 管理者メールが決まっている |
| 2 | 問い合わせメールを設定する | 運営 | 送受信用メールアドレスが決まっている |
| 3 | 管理画面に問い合わせカテゴリを設定する | 運営 | 通報、削除依頼、スポンサー等の分類がある |
| 4 | AI分類・返信下書きの対象範囲を設定する | 運営/開発 | AIが外部送信しないルールがある |
| 5 | 初期FAQ/回答テンプレートを登録する | 運営 | 投稿、削除、通報、施設修正の標準回答がある |
| 6 | 通報・削除依頼の一時非公開ルールを確認する | 運営 | 緊急停止権限者が決まっている |
| 7 | 外部サービス費用台帳を登録する | 運営/開発 | 契約者、請求先、公式URLが分かる |
| 8 | 月次確認日と担当者を決める | 運営 | 費用・問い合わせ・通報の確認が必要 |

## 開始時点で決まっている必要がある運営事項

- [ ] 運営主体・連絡先
- [ ] 管理者アカウントと権限
- [ ] 問い合わせメールアドレス
- [ ] 問い合わせカテゴリ
- [ ] AI下書きの利用範囲
- [ ] 回答ナレッジの承認者
- [ ] 削除依頼の対応窓口
- [ ] スポンサー問い合わせの対応窓口
- [ ] 外部サービス費用確認の担当者
- [ ] 緊急停止の権限者
