# 運営KPI: CLEAN TOILET(仮)

更新日: 2026-06-20

## 運営KPI

| KPI | 測定対象 | 目標/閾値 | 過負荷の兆候 |
|---|---|---|---|
| 問い合わせ件数 | メール/フォーム/管理画面の新規問い合わせ数 | 週次で確認 | 1人運営で週30件超が継続 |
| 一次応答時間 | 問い合わせ受信から初回返信まで | 原則3営業日以内、高リスク通報は24時間以内確認 | 目標超過が週20%以上 |
| 解決時間 | 問い合わせ受信からクローズまで | 通常7営業日以内、スポンサー相談10営業日以内 | 未解決が積み上がる |
| AI下書き採用率 | AI下書きを人間が修正少なく使えた割合 | 初期は参考指標 | 採用率が低く運営負荷が減らない |
| ナレッジ再利用数 | 承認済み回答ナレッジが使われた件数 | 月次で増加傾向 | 同じ問い合わせに毎回手作業回答 |
| 高リスク通報件数 | 個人情報、人物、誹謗中傷、不適切画像 | 日次確認 | 対応待ちが24時間超 |
| 削除依頼件数 | 写真削除、掲載削除、施設情報削除 | 週次確認 | 法務確認が必要な案件が増える |
| スポンサー問い合わせ件数 | 企業/施設からの掲載相談 | 週次確認 | 返信遅延で商談機会を失う |
| 外部サービス費用アラート件数 | 70%/85%/100%/120%アラート | 月次確認 | 連続して警告ラインを超える |

## 運営が回らなくなる条件

| 条件 | 観測指標 | 対処 |
|---|---|---|
| 問い合わせが処理能力を超える | 未解決問い合わせが2週間以上増え続ける | FAQ整備、テンプレート化、運営者追加を検討 |
| 通報対応が遅れる | 高リスク通報の24時間超過 | 一時非公開ルールと優先対応を見直す |
| AI下書きが役に立たない | AI下書き採用率が低い | ナレッジ整備、カテゴリ設計を見直す |
| 費用確認が追いつかない | コストアラート未確認が残る | 月次確認担当と通知先を固定する |
