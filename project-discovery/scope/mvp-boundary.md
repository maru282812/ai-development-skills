# MVP境界（仮説）

更新日: 2026-06-20

## 最初に必要な機能

| 機能 | 理由 | 優先度 |
|---|---|---|
| 今すぐトイレ | ユーザーが焦っている時に検索条件を考えず使える入口が必要 | MVP |
| 現在地から近いトイレ検索 | 外出時の即時課題に直結する | MVP |
| 駅名検索 | 駅攻略、号車、改札内/外の価値を出すため | MVP |
| 商業施設の代替候補表示 | フル攻略は後回しにしつつ、現在地/駅周辺で使える逃げ道を残すため | MVP候補 |
| 地図上のトイレ表示 | 近さと位置関係、代替候補を直感的に把握するため | MVP |
| トイレ詳細 | 階数、改札内/外、男性/女性/共用/多目的、個室数、写真ステップ、評価をまとめて判断するため | MVP |
| 写真ステップ式ルート投稿 | 文字入力負荷を下げ、行き方情報を資産化するため | MVP |
| 写真投稿の公開前自動スキャン | 人物・鏡・個人情報・不適切画像を公開前に止めるため | MVP |
| トイレ内写真の投稿前確認 | トイレ内写真のプライバシーリスクを毎回投稿前に確認させるため | MVP |
| 軽量状態投稿 | 混みやすい、空いていた、清潔、入口が分かりにくい等を短時間で残すため。ゲスト投稿も許可する | MVP |
| 新規トイレ地点提案 | 初期データ拡充に必要。ログイン必須で、重複・短時間大量登録を制限する | MVP |
| 清潔度評価 | ユーザーが最も判断したい品質情報の一つ | MVP |
| 安心度評価 | このプロダクト固有の価値を表す中核指標 | MVP |
| トイレ数・種別の記録 | 個室数や男性/女性/共用/多目的の違いが実用判断に直結するため | MVP |
| スポンサー目印/コードの基本表示 | 導線上の広告価値を検証し、収益仮説を早期に確認するため | MVP候補 |
| 施設情報修正/オーナー申請フォーム | 誤情報を減らし、Phase2の公式情報編集につなげるため | MVP候補 |
| 外部サービス費用/アップロード先管理 | 地図・画像・AI・配布・決済の維持費とAPI制限を管理し、運営継続性を確認するため | MVP候補 |
| 問い合わせ管理/メール設定 | 通報、削除依頼、スポンサー相談、施設修正依頼を受けるため | MVP候補 |
| AI返信下書き/回答ナレッジ管理 | 問い合わせ対応を蓄積し、運営負荷を下げるため | MVP候補 |
| 投稿の通報 | 不適切投稿・個人情報・迷惑投稿に対応するため | MVP |
| 管理者の非公開化 | 投稿型サービスとして最低限の運用安全性を確保するため | MVP |
| 投稿者への注意通知・投稿制限 | 悪質投稿に段階対応し、善意の投稿者をいきなりBANしないため | MVP |

## 無くてもよい機能

| 機能 | 理由 |
|---|---|
| 高度なSNS機能 | 初期価値は検索・ルート投稿・SNSカード草案で検証できる |
| フォロー / DM | トイレ情報共有の初期価値に必須ではない |
| 店舗/スポンサー向けセルフサーブ管理画面 | 初期は申請フォームと運営手入力で広告価値・施設側ニーズを検証できる |
| リアルタイム混雑 | センサーや継続投稿が必要で初期コストが高い |
| 決済/クーポン自動消込 | 初期はスポンサーコード表示と簡易計測で検証可能 |
| 一般投稿動画 | 人物映り込み・容量・審査負荷が高い。まずは写真ステップにする |
| 海外データ公開 | 初期は日本国内に集中し、海外は将来対応できる構造だけ残す |
| AI単独の問い合わせ自動回答 | 誤回答リスクがあるため、初期はAI下書きと人間承認にする |

- 子ども連れ向けタグ（おむつ台、ベビーチェア等）
- 高齢者・介助者向けタグ（多目的、手すり、段差等）
- ペット連れ向けタグ
- 混雑しやすさ・待ち時間の詳細投稿
- お気に入り / 行きたい登録
- 施設オーナーによる公式情報編集（Phase2）
- 商業施設のフロア別フル攻略
- SNS共有カードの高度なデザイン展開
- 称号・エリア制覇・貢献ランキング
- 公式スポンサー掲載の管理画面
- 施設/テナント向けスポンサーコード管理
- 複数店舗管理、請求/契約管理
- 多言語UI/海外データ公開

## 段階リリース案

| 段階 | 目的 | 主な内容 |
|---|---|---|
| 先行公開（2027年1月想定） | 初期ユーザーで現在地周辺検索・駅攻略・写真ステップ投稿の価値検証 | iOS TestFlight 先行、Android クローズドテスト同時期開始、今すぐトイレ、現在地検索、駅検索、写真ステップ投稿、ゲスト軽量投稿、地点提案、管理 |
| 正式公開（2027年6月想定） | 日本国内で一般ユーザーに使える最低品質で提供 | アプリストア公開、現在地周辺検索、駅攻略、商業施設の代替候補表示、レビュー品質改善、地点提案の重複/大量登録制御、通報対応、問い合わせ管理、スポンサー目印の試験導入 |
| Phase2 | 情報の深さとスポンサー価値を強化 | 商業施設攻略、詳細タグ、SNSカード、称号、スポンサーコード、施設/テナント広告、施設オーナー簡易編集、公式ルートカード |
| Phase3 | 事業化と社会的信用を強化 | 認定制度、エリアスポンサー、自治体/商業施設連携、複数店舗管理、請求/契約管理、データレポート |
