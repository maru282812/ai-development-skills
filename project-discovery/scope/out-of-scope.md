# 対象外（今回作らないもの）

更新日: 2026-06-20

## MVP対象外

| 項目 | 理由 |
|---|---|
| CLEAN TOILET 認定制度の本格運用 | 評価データと運用基準が必要。初期から制度化すると審査・責任が重くなる |
| 店舗・施設向け有料管理画面 | MVPでは修正依頼/オーナー申請フォームと運営手動反映で検証し、セルフサーブ編集はPhase2に回す |
| スポンサー課金・決済 | 法務・返金・請求運用が必要。MVP価値検証後に分離して設計する |
| 自動広告配信システム | 初期は運営手入力のスポンサー枠で価値検証する |
| アフィリエイトリンク | スポンサーコードと公式掲載に集中するため扱わない |
| クーポン/POS連携 | スポンサーコード表示で検証し、自動消込は後続にする |
| リアルタイム混雑表示 | センサー連携や高頻度投稿が必要で初期開発負荷が高い |
| 一般ユーザー動画投稿 | 人物映り込み・容量・審査負荷が高いため、写真ステップ投稿を優先する |
| 予約機能 | トイレ利用の予約は一般的な利用シーンに合いにくい |
| SNSタイムライン | 初期のコア価値は検索・判断・投稿であり、交流機能ではない |
| 完全な全国データ整備 | 初期は駅・改札・施設単位で密度を作る方が現実的 |
| オフライン地図 | 初期はオンライン前提で十分。災害時用途とは切り分ける |
| 医療アドバイス | 体調・疾患に関する診断や助言は扱わない |
| 海外データ公開 | 初期リリースは日本国内に集中する。海外は将来対応できる構造だけ残す |
| AI単独による問い合わせ自動回答 | 誤回答・法務・削除判断のリスクがあるため、初期はAI下書きと人間承認にする |

## 将来検討に回すもの

- 施設オーナー認証
- スポンサー/テナント向け広告管理画面
- スポンサーコードの自動発行・消込
- 複数店舗管理、請求/契約管理
- 自治体・商業施設との公式連携
- 多言語対応
- 海外データ公開
- 観光客向け特集
- 高齢者・介助者向けアクセシビリティ詳細項目
- ペット可/不可などの詳細フィルター
