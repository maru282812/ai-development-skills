# ゴール

更新日: 2026-06-20

## 成功とは何か

ユーザーが外出先でトイレを探すときに、単に場所を見つけるだけでなく「今すぐ行ける」「ここなら安心して使えそう」「迷わず辿り着ける」と判断できる状態を作る。

## KPI候補

測定可能化は後続の metrics-discovery で行う。現時点では候補に留める。

| 観点 | KPI候補 | 優先度 |
|---|---|---|
| 利用 | `今すぐトイレ` の利用数 | MVP |
| 利用 | 駅名検索数 / 駅攻略ページ閲覧数 | MVP |
| 投稿 | 写真ステップ式ルート投稿数 | MVP |
| 投稿 | 軽量状態投稿数（混雑、清潔、個室数、最終確認） | MVP |
| 情報量 | 登録トイレ地点数 | MVP |
| 情報量 | 駅/施設別の階数・個室数・改札内外情報の充足率 | MVP |
| 品質 | 最終確認日が新しい地点比率 | MVP |
| 安心 | 「役に立った」反応数 / 安心度評価数 | Phase2 |
| 運営 | 通報対応時間 | MVP |
| 運営 | 地図API/画像ストレージ/AI画像処理の月額見込みと実績 | MVP候補 |

| 事業 | スポンサー問い合わせ数 / スポンサーコード表示数 | Phase2 |

| 認定 | CLEAN TOILET 認定候補施設数 | 将来 |

## ユーザー価値

- 外出時のトイレ不安を減らせる
- 近いだけでなく、安心して使えそうな場所を選べる
- 駅の号車・改札・階数・代替施設など、初めての場所でも行動に移せる判断材料が得られる
- 写真ステップにより、文字を読まなくても迷わず辿り着ける
- 投稿によって、同じ不安を持つ人を助けた実感、称号、SNS共有カードを得られる

## 事業価値

- 清潔で安心できるトイレを維持している施設が評価される
- 店舗・施設の集客や評判向上につながる可能性がある
- 施設内テナントや周辺企業が、トイレ導線上の自然な目印広告・スポンサーコードとして参加できる
- 将来的にスポンサー掲載、公式ルートカード、施設紹介、認定制度の収益化余地がある
