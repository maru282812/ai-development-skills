# ユーザー

更新日: 2026-06-20

## 利用者種別

| 区分 | 内容 | 優先度 |
|---|---|---|
| 主利用者 | 外出時にトイレへの不安を抱える一般ユーザー | MVP |
| 主利用者 | お腹が弱い方、過敏性腸症候群などで急なトイレ不安がある方 | MVP |
| 副利用者 | 子ども連れの保護者 | MVP |
| 副利用者 | 高齢者、介助者 | Phase2 |
| 副利用者 | 旅行者、観光客 | Phase2 |
| 副利用者 | ペット連れの外出者 | Phase2 |
| 施設側 | トイレを貸している店舗・商業施設・公共施設。MVPでは修正依頼/オーナー申請、Phase2以降は公式情報編集 | MVP/Phase2以降 |
| 運営者 | 投稿内容・施設情報・通報を管理するプロジェクト運営者 | MVP |
| 支援者 | クラウドファンディング支援者、初期サポーター | MVP/Phase2 |

## 主利用者

MVPでは「外出時に近くの安心できるトイレを素早く判断したい人」を主対象にする。

## 副利用者

子ども連れ、旅行者、高齢者、ペット連れは、検索条件やレビュー観点が広がりやすい。MVPでは基本利用に含めるが、専用フィルターや詳細タグは Phase2 以降に回す。

## 運営者

MVPでも、写真・レビュー投稿を扱うため、最低限の管理者が必要。投稿の非公開化、通報確認、施設情報の修正依頼/オーナー申請対応を行う。
