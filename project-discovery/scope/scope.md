# スコープ

更新日: 2026-06-20

## 境界サマリ

CLEAN TOILET(仮) は、外出時にトイレへの不安を抱える人が、現在地・駅・施設から「今すぐ行ける安心候補」を探し、写真ステップ式の行き方、清潔度、安心度、混雑傾向、個室数、階数、男性/女性/共用/多目的などをもとに判断できる安心トイレ攻略アプリとして始める。

初期リリース対象国は日本国内のみとする。海外対応は将来候補だが、データ構造上は国、地域、言語、通貨、タイムゾーン、信頼度を扱える余地を残す。

## MVPの線

MVPでは「ユーザーが考えずに最短で使えること」と「投稿者が長文を書かずにルート情報を残せること」に集中する。

- `今すぐトイレ` から最短候補・安心候補・代替候補を確認できる
- 現在地または駅名からトイレを探せる
- トイレ詳細で階数、改札内/外、男性/女性/共用/多目的、個室数、混雑傾向、写真ステップを確認できる
- ユーザーが写真 + 選択式チップでルートカードを投稿できる
- 投稿者の称号・貢献・SNS共有カードにつながる
- 管理者が不適切投稿を非公開化できる
- スポンサー目印とスポンサーコードを基本表示できる
- 施設情報修正/オーナー申請を受け付け、運営が手動確認できる
- 問い合わせをメール/管理画面で受け、AI補助と回答ナレッジで運営負荷を下げられる

## 対象・対象外の要点

対象:
- 一般ユーザー向けのトイレ検索・閲覧・投稿
- 最低限の投稿管理
- 地図・位置情報・画像保存・レビュー保存
- 駅/施設/フロア/トイレグループの階層情報
- ルート上の目印としてのスポンサー表示とスポンサーコードの基本表示
- 施設情報修正/オーナー申請の受付

対象外:
- 認定制度の本格運用
- 店舗・施設・スポンサー向けセルフサーブ管理画面
- 自動広告配信、決済、スポンサー請求
- 混雑リアルタイム検知
- 一般ユーザー動画投稿
- 全国完全網羅の初期データ整備
- 海外データ公開
- AI単独による問い合わせ自動回答
