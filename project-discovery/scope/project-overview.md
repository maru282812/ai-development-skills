# プロジェクト概要: CLEAN TOILET(仮)

更新日: 2026-06-19

## 一言説明

安心して使えるトイレまでの最短導線と判断材料を、駅・施設・街の攻略情報として可視化するアプリ。

## 解決したい課題

現在はトイレの「場所」は調べられるが、「今すぐ行けるか」「どの号車・改札・階から近いか」「実際に安心して使えるか」は分かりにくい。外出時にトイレ不安を抱える人にとって、清潔さ、雰囲気、入りやすさ、個室数、混雑、行き方の分かりやすさが分からないことは大きなストレスになる。

## 背景

プロジェクトオーナー自身が学生時代からお腹が弱く、外出時に常にトイレの不安を抱えていた。初めて行く場所や商業施設ではまずトイレを探し、車・電車移動中も不安がつきまとう経験があった。

同じ不安を持つ人は少なくない。お腹が弱い人、子ども連れ、高齢者、旅行者、ペット連れにとって、安心できるトイレ情報は外出のしやすさに直結する。

## なぜ作るのか

- ユーザーが「今すぐここへ行けば大丈夫」と判断できる情報を増やすため
- トイレ不安による外出の心理的ハードルを下げるため
- 清潔で安心できるトイレを維持している店舗・施設が正当に評価される仕組みを作るため
- 投稿者が写真ステップ、称号、SNSカード、貢献実感によって投稿したくなる仕組みを作るため
- 施設や企業が、導線の目印・スポンサーコード・エリア協賛として自然に広告参加できる仕組みを作るため
- 将来的に、安心して貸してくれる場所が感謝される社会的な評価基盤を作るため
