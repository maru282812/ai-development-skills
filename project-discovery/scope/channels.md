# 利用環境

更新日: 2026-06-19

| チャネル | 位置づけ | 優先度 | メモ |
|---|---|---|---|
| iPhoneアプリ | 外出時の主利用環境 | MVP | Expo + React Native で Android と共通開発し、TestFlight を先行公開に使う |
| Androidアプリ | 外出時の主利用環境 | MVP | iOS と同時期にクローズドテストを開始し、一般公開は近接リリースを目指す |
| Web / PWA | LP・管理画面・スポンサー申込・簡易デモ | 補助 | 本体アプリの先行形態にはせず、周辺導線として扱う |
| 管理画面Web | 投稿管理・通報対応・スポンサー簡易管理 | MVP | モバイルアプリ内ではなくWeb管理画面でよい |
| SNS共有カード | 投稿後・称号獲得時の拡散導線 | Phase2候補 | デザイン品質が重要。現実世界とバーチャル的なポップさを融合する |
| LINE / LIFF | 通知・簡易アクセス | 将来候補 | 初期から入れるとスコープが広がる |

## 利用モード

| モード | 目的 | 広告表示 |
|---|---|---|
| 緊急モード | `今すぐトイレ` から最短候補を出す | 非表示または最小化 |
| 安心モード | 清潔度・安心度・写真を見て選ぶ | 目印広告のみ |
| 攻略モード | 駅・号車・改札・階数・商業施設を詳しく見る | 目印広告/スポンサーコードを表示可 |
| 投稿モード | 写真ステップや状態を投稿する | 投稿完了後にSNSカード/スポンサー表示 |
| 探索モード | 称号・エリア制覇・貢献を見る | スポンサー協賛と相性あり |

## 推奨

MVPは「Expo + React Native で iOS / Android を共通開発、管理画面は Web」。公開順は iOS TestFlight を先行し、Android は同時期にクローズドテストを開始する。Web/PWA は本体ではなく、LP・管理画面・スポンサー申込導線・簡易デモに限定する。
