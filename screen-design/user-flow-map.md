# 画面遷移設計

更新日: 2026-06-22

## 初回利用

```text
アプリ起動
  -> U-00 初回同意/位置情報説明
    -> 位置情報許可: U-01 地図ホーム
    -> 位置情報拒否: U-04 駅検索
    -> ログインする: U-13 ログイン/登録
```

## 今すぐトイレ

```text
U-01 地図ホーム
  -> U-02 今すぐトイレ
    -> 候補選択: U-07 ルートカード閲覧
    -> 比較したい: U-03 候補比較/検索結果
    -> 位置情報拒否/0件: U-04 駅検索
    -> 到着後: U-11 軽量状態投稿
```

緊急時ルール:
- 広告カード、バナー、全画面広告を出さない
- スポンサーはルート上の実用的な目印だけ小さく表示できる
- 候補選択前にスポンサーコードを押し出さない

## 現在地周辺検索

```text
U-01 地図ホーム
  -> ピン選択: U-06 トイレ詳細
  -> リスト表示: U-03 候補比較/検索結果
  -> 未登録発見: U-12 新規地点提案
```

## 駅攻略

```text
U-04 駅検索
  -> U-05 駅攻略
    -> 条件切替(路線/改札/階数/改札内外)
    -> 候補比較: U-03 候補比較/検索結果
    -> トイレ選択: U-06 トイレ詳細
    -> 号車情報なし: U-12 新規地点提案 または U-24 問い合わせフォーム
```

商業施設はMVPでは `U-03` と `U-05` の代替候補として表示する。Phase2で `U-22 商業施設フロア別攻略` へ分離する。

## トイレ詳細から行く

```text
U-06 トイレ詳細
  -> ルートを見る: U-07 ルートカード閲覧
  -> 状態を更新: U-11 軽量状態投稿
  -> 行き方を投稿: U-08 写真ステップ投稿
  -> 通報: U-14 通報フォーム
  -> スポンサーコード: U-16 スポンサーコード表示
  -> 施設情報修正: U-15 施設情報修正/オーナー申請
```

## 写真ステップ投稿

```text
U-06 トイレ詳細
  -> U-08 写真ステップ投稿
    -> 未ログイン: U-13 ログイン/登録
    -> トイレ内写真あり: U-09 トイレ内写真確認モーダル
    -> 投稿: U-10 投稿スキャン/投稿結果
      -> 公開: U-17 マイページ または U-19 SNS共有カード作成(Phase2)
      -> 自動ぼかし済み: U-10 投稿結果
      -> 確認待ち: U-10 投稿結果
      -> 非公開/注意: U-10 投稿結果
```

## 軽量状態投稿

```text
U-06 トイレ詳細 または U-07 ルートカード閲覧
  -> U-11 軽量状態投稿
    -> ゲスト投稿: 完了表示
    -> ログイン済み投稿: U-17 マイページへ履歴反映
```

## 新規地点提案

```text
U-01 地図ホーム / U-05 駅攻略 / U-06 トイレ詳細
  -> U-12 新規地点提案
    -> 未ログイン: U-13 ログイン/登録
    -> 重複候補あり: 既存地点へ情報追加
    -> 同一建物内追加: 続けて入力
    -> 提案完了: U-10 投稿スキャン/投稿結果
```

## 通報/削除依頼/問い合わせ

```text
U-06 トイレ詳細 / U-07 ルートカード閲覧
  -> U-14 通報フォーム
    -> 送信完了
    -> 管理側: A-04 通報管理

U-17 マイページ / U-24 問い合わせフォーム
  -> 削除依頼
    -> 受付済み/対応中/対応完了のみ表示
    -> 管理側: A-09 問い合わせ管理
```

ユーザー向けには具体的な対応期限を表示しない。

## 支援者導線

```text
メールリンク/支援者コード
  -> U-13 ログイン/登録
  -> U-18 支援者連携/バッジ設定
    -> バッジ表示/非表示
    -> 名前掲載希望: プレビュー確認
    -> 削除依頼: U-24 問い合わせフォーム
```

## 管理者導線

```text
A-00 管理ログイン
  -> A-01 管理ダッシュボード
    -> 投稿対応: A-02 投稿管理 -> A-03 写真審査
    -> 通報対応: A-04 通報管理
    -> 地点対応: A-05 地点/階層管理
    -> 施設申請: A-06 施設情報修正/オーナー申請管理
    -> スポンサー: A-07 スポンサー簡易管理
    -> 費用/保存先: A-08 外部サービス費用/アップロード先管理
    -> 問い合わせ: A-09 問い合わせ管理 -> A-10 メール設定/回答ナレッジ
    -> 支援者: A-11 支援者管理
    -> 公開前レビュー: A-12 法務/税務レビュー管理
    -> KPI/費用: A-13 KPI/コストダッシュボード
```

U-15 施設情報修正/オーナー申請
