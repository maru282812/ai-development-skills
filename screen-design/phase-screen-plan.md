| 軽量状態投稿 | U-11 |
| 新規地点提案 | U-12 |
| 通報フォーム | U-14 |
| 施設情報修正/オーナー申請 | U-15 |
| 管理ログイン | A-00 |
| 管理ダッシュボード | A-01 |

| 写真審査 | A-03 |
| 通報管理 | A-04 |
| 地点/階層管理 | A-05 |

- 商業施設は詳細攻略ではなく、代替候補として検索結果/駅攻略/詳細に表示する

## Public Release

目的: 一般公開に必要な運用、法務、費用監視、問い合わせ対応を整える。

| 追加/強化する画面 | 画面ID |
|---|---|
| 法務/税務レビュー管理 | A-12 |
| KPI/コストダッシュボード | A-13 |
| LP/スポンサー申込入口 | PUB-01 |
| 利用規約/プライバシー導線 | PUB-03 |

変更方針:
- 公開前レビューの高重要度指摘が残っている場合、正式公開チェックをNGにする
- 費用は先行ベータ30,000円、MVP一般公開50,000円を基準に、70%/85%/100%/120%を表示する
- 通報/削除/問い合わせ対応の管理状態を公開運用向けに見える化する

## Phase2

目的: 投稿動機、SNS拡散、スポンサー価値、施設側価値を強化する。

| 追加/強化する画面 | 画面ID |
|---|---|
| SNS共有カード作成 | U-19 |
| 称号/貢献ダッシュボード | U-20 |
| 詳細タグ/お気に入り | U-21 |
| 商業施設フロア別攻略 | U-22 |
| 施設オーナー簡易編集 | O-01 |
| 公式ルートカード/スポンサーコード管理 | O-02 |
| 掲載レポート | O-03 |

変更方針:
- SNSカードは広告なし/スポンサー付きの選択式にする
- 称号は投稿者の所有感を出すが、ゲスト投稿は反映しない
- 施設オーナーは直接公開ではなく、保存/申請/運営承認の状態を持つ

## Phase3

目的: 事業化、社会的信用、B2B運用へ広げる。

| 追加/強化する画面 | 画面ID |
|---|---|
| 認定施設紹介 | U-23 |
| 認定管理 | A-14 |
| 請求/契約管理 | A-15 |
| 複数施設管理 | A-16 |
| データレポート | O-04 |

変更方針:
- CLEAN TOILET認定は未確認の認定表示を出さない
- 請求/契約、掲載期間、返金、税区分、インボイス対応は管理画面に分離する
- 自治体/商業施設連携や複数店舗運用に対応する
