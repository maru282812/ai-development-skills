## API/データ依存

| screen_id | 必要データ/操作 | 備考 |
|---|---|---|
| U-01/U-02/U-03 | 現在地、近傍トイレ、安心度、清潔度、注意フラグ | PostGIS/地図API想定 |
| U-04/U-05 | 駅、路線、改札、階数、号車、代替施設 | 公式情報を正本にする |
| U-06 | トイレ詳細、写真ステップ、評価、スポンサー | PR表示と評価を分離 |
| U-08/U-10 | 画像アップロード、スキャン、ぼかし、投稿状態 | トイレ内写真確認ログ必須 |
| U-11 | 軽量状態投稿 | ゲスト可、信頼スコア対象外 |
| U-12 | 地点提案、重複候補、建物セッション | ログイン必須 |
| U-18/A-11 | 支援者コード、同意、バッジ、掲載状態 | コードは平文保存しない |
| A-08/A-13 | 外部サービス台帳、費用実績、閾値 | MVPは手入力/CSVで可 |
| A-12 | レビュー対象、版、指摘、対応状態 | 高重要度未解決なら公開NG |

## 実装時の注意

- 位置情報拒否時の代替導線を必ず用意する
- 投稿画面は写真とチップ中心にし、長文入力を必須にしない
- トイレ内写真確認は毎回表示する
- ユーザー向け削除依頼状態に具体的な期限を出さない
- スポンサーはPR/Sponsored表記を必須にし、評価指標と混ぜない
- 管理画面はスマホアプリと別でPC前提にする
