# 保守ループ既定（/loop 用）

<!-- factory-bootstrap が設置。/loop がこの repo で起動されたときの既定の巡回内容。 -->
<!-- Build（新機能の製造）はこのループでやらない — それは /goal / phase-runner の仕事。 -->

各周回で以下を上から順に確認し、該当があるものだけ対応する。

## 巡回内容

1. **未完了作業**: phase-status.md / TODO / FIXME に残っている未完了項目の確認
2. **CI / ゲート**: 直近の CI 失敗・ローカルゲート（docs/VERIFY.md §1）の赤の修正
3. **PR**: 未対応のレビューコメント・merge conflict の解消
4. **依存関係**: セキュリティアラート（audit）の確認 — 更新の適用は報告のみ
5. **小さな品質改善**: 明らかな typo・dead code・軽微な lint 警告の解消

## 線引き（phase-runner と同一哲学）

- **自動で直してよい**: 単一ファイル・小diff・ロジック非変更・UI文言・明らかな小バグ。
- **直さず報告に溜める**: DB/スキーマ/認可/課金/外部連携/破壊系/ロジック変更/仕様が曖昧なもの。
  docs/VERIFY.md §4 の Human Gate に該当するものは必ず止める。

## 各周回の終わりに

- 何かを変更した場合は docs/VERIFY.md §1 の Gates を実行し、緑を確認してから終わる。
- 対応した内容と溜めた報告を短く記録する（変更なしの周回は noop）。
