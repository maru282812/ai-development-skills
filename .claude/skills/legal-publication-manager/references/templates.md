# 法務成果物 再利用テンプレート集

`legal-publication-manager` の **原本テンプレート**。各プロジェクトでは、ここから必要な雛形を `legal/templates/` に複製し、`<...>` プレースホルダをプロジェクト値に差し替えて使う。

> **重要 / これらは最終版ではない**
> - 法的に有効であると断定したものではない。**雛形のたたき台**。
> - 公開前に必ず `要専門家レビュー`（弁護士・専門家）または `事業責任者確認` を通すこと。
> - 「弁護士レビュー済み」と書かない。各文書冒頭のステータス行を残したまま管理する。
> - 個人情報の分類・取得項目は [[data-discovery]] の結果に従う。ここで独自に確定しない。

## 共通プレースホルダ

| プレースホルダ | 意味 |
|---|---|
| `<サービス名>` | サービス・プロダクト名 |
| `<運営者名>` | 運営事業者名・屋号 |
| `<所在地>` | 運営者の所在地 |
| `<問い合わせ先>` | 問い合わせ窓口（メール / フォームURL） |
| `<決済方法>` | 利用する決済手段 |
| `<取得する個人情報>` | 取得するデータ項目（data-discovery 由来） |
| `<外部委託先>` | 委託先・第三者提供先 |
| `<準拠法>` / `<管轄裁判所>` | 準拠法・合意管轄 |
| `<施行日>` / `<改定日>` | 効力発生日・改定日 |

各テンプレート冒頭には次のステータス行を残す：

```md
> ステータス: 雛形適用済み（未差替プレースホルダあり） / 要専門家レビュー / 事業責任者確認待ち
> 最終更新日: <YYYY-MM-DD> ／ レビュー担当: <担当>
```
